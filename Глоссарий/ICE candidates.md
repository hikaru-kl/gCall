**ICE candidate** — это потенциальный сетевой адрес, по которому клиент **может быть доступен** для соединения.

## Что такое ICE

**ICE (Interactive Connectivity Establishment)** — механизм, который:

- собирает возможные пути соединения
    
- тестирует их
    
- выбирает лучший
    

## Типы ICE candidates

### 1. Host candidate

- локальный IP (например, 192.168.x.x)
    
- работает только в одной сети
    

### 2. Server Reflexive (srflx)

- публичный IP, полученный через STUN
    
- часто используется для P2P
    

### 3. Relay candidate

- адрес TURN сервера
    
- используется как fallback
    

## Как используются

1. Клиенты обмениваются ICE candidates через signaling
    
2. Пары адресов тестируются
    
3. Выбирается путь с наименьшей задержкой
    

## Важное

- ICE candidates **отправляются асинхронно**
    
- соединение может устанавливаться ещё до получения всех candidates
