**[WebRTC]([Немного о WebRTC: что где использовать и случай из практики / Хабр](https://habr.com/ru/articles/501416/)) (Web Real-Time Communication)** — это набор стандартов и реализаций для **передачи аудио, видео и данных в реальном времени** с минимальной задержкой.

## Что включает WebRTC

WebRTC — это не один протокол, а **целый стек**:

- Захват медиа (mic / camera)
    
- Кодирование (Opus, VP8, H.264)
    
- Передача (RTP / SRTP)
    
- [[NAT traversal]] ([[ICE candidates]] / STUN / TURN)
    
- Шифрование (DTLS, SRTP)
    
- Контроль качества (RTCP)
    

## Ключевые свойства

- Низкая задержка (десятки миллисекунд)
    
- Шифрование по умолчанию
    
- Работает поверх UDP
    
- Поддерживается браузерами и нативными SDK
    

## Чего WebRTC НЕ определяет

- Signaling протокол
    
- Логику комнат
    
- Авторизацию
    
- UI
    

Эти части реализуются приложением самостоятельно.

## Где используется

- Discord
    
- Zoom
    
- Google Meet
    
- Telegram Calls
