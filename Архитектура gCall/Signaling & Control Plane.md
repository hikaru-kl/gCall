**(Управление соединениями)**

> Мозг системы, но без тяжёлого трафика

### Отвечает за

- Аутентификацию
    
- Комнаты
    
- Кто с кем соединяется
    
- Обмен SDP / ICE
    
- События (mute, leave, kick)
    

### Технологии

- Go / Rust / Node.js
    
- WebSocket
    
- gRPC
    
- Redis (presence)
    

### НЕ делает

- не передаёт медиа
    
- не работает с UDP
